# Dictionary Sources

The `botok_general` dialect pack bundled with Teahouse Tibetan contains only data
whose redistribution is explicitly permitted. Please do not re-add material
from commercial or all-rights-reserved dictionaries without written permission.

## Tokenization Wordlists (botok-data)

Source: [Esukhia/botok-data](https://github.com/Esukhia/botok-data) — general dialect pack  
License: [CC-BY 4.0](https://creativecommons.org/licenses/by/4.0/) for the
curated pack; individual files are public domain unless marked otherwise.

Files:
- `words/tsikchen.tsv` — main Tibetan wordlist (~31K entries)
- `words/uncompound_lexicon.tsv` — compound word components
- `words/ancient.tsv` — classical/archaic forms
- `words/exceptions.tsv` — proper nouns and exceptions
- `words/dagdra.tsv` — homophone disambiguation entries
- `words_non_inflected/particles.tsv` — grammatical particles

These files provide Tibetan word forms, part-of-speech tags, and lemmas.
They do **not** contain English definitions.

## Definition Dictionary (84000 glossary)

Source: [84000: Translating the Words of the Buddha](https://read.84000.co/glossary/downloads.html)  
License: [Creative Commons Attribution 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/)

File:
- `words/84000.tsv` — canonical Buddhist terminology (~25K entries)

The bundled copy is derived from the 84000 public glossary data. Attribution is
provided in the extension's options page and NOTICE file.

## Definition Dictionary (Hopkins)

Source: [Jeffrey Hopkins' Tibetan-Sanskrit-English Dictionary — Dharma Drum Buddhist College digital edition](https://glossaries.dila.edu.tw/data/hopkins.dila.pdf)  
License: [Creative Commons Attribution-ShareAlike 3.0 Unported (CC BY-SA 3.0)](https://creativecommons.org/licenses/by-sa/3.0/)

File:
- `words/hopkins.tsv` — Buddhist philosophy and general vocabulary (~18.5K entries)

The bundled TSV is generated from the CC BY-SA source using `tools/build-hopkins.js`.
Because the license is ShareAlike, the derived dictionary data is itself
distributed under CC BY-SA 3.0.

## POS Lexicon (ACTib)

Source: [Annotated Corpus of Classical Tibetan (ACTib II)](https://doi.org/10.5281/zenodo.822537), via [Esukhia bo-pos](https://github.com/Esukhia/bo-pos)  
License: Creative Commons Attribution 4.0 International (CC BY 4.0)

- `words/actib_pos.tsv` — part-of-speech tags for ~90K forms. Used only as a
  fallback to fill in missing POS tags; contributes no definitions. Filtered
  to forms of <= 2 syllables plus forms already present in the bundled
  wordlists. Generated by `tools/build-actib-pos.js`. Machine-tagged corpus
  data, so tags are shown as "likely" in tooltips.

## POS Lexicon (SOAS)

Source: [SOAS POS-tagged corpus of Classical Tibetan](https://doi.org/10.5281/zenodo.574878), via [Esukhia bo-pos](https://github.com/Esukhia/bo-pos)  
License: Creative Commons Attribution 4.0 International (CC BY 4.0)

- `words/soas_pos.tsv` — multi-tag part-of-speech data for ~5.5K forms,
  human-annotated. Words attested in more than one category emit one row per
  tag so tooltips can show every attested POS. Generated by
  `tools/build-soas-pos.js`.

## Inferred and Curated POS layers

- `words/gloss_pos_inferred.tsv` — POS tags inferred at build time from
  high-confidence English gloss patterns in Hopkins and 84000 (e.g. "to …"
  verb glosses, `<person>`/`<place>` markers). Generated by
  `tools/build-gloss-pos.js`.
- `words/pos_overrides.tsv` — hand-curated corrections; the highest-priority
  POS source. Add a row here when corpus tags are wrong for a word.

POS sources are ranked: `pos_overrides` > explicit dictionary tags >
gloss-inferred > SOAS > ACTib.

## Dictionaries that are NOT bundled

Teahouse Tibetan does **not** ship the following popular dictionaries unless and
until their authors or publishers grant explicit redistribution permission or
release them under an open license:

- Jim Valby's Tibetan-English dictionary
- Ives Waldo's Tibetan-English glossary compilation
- Tsepak Rigdzin's *Tibetan-English Dictionary of Buddhist Terms*

These works are copyrighted by their respective authors. Several existing apps
have obtained individual permission; Teahouse Tibetan must do the same before
including them.

## Rebuilding

To rebuild the tokenization wordlists from upstream botok-data:

```bash
# Clone source repository
git clone https://github.com/Esukhia/botok-data.git /tmp/botok-data

# Install build dependencies and run
npm install
npm run build:dictionaries /tmp/botok-data
```

The build script is at `tools/build-dictionaries.js`.
